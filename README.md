# gui4dsh

为 **dsh（DeepSeek Harness）** 打造的 Web 前端，支持手机远程连接。

dsh 是 DeepSeek 的 CLI 智能体框架（`@deepseek-ai/dsh`，`npx @deepseek-ai/dsh` 启动）。它自带的 web 界面没有自动化/统计/触发器/分组等功能，也无法安全地公网访问。gui4dsh 作为**网关层**：拉起 dsh 作为引擎，用 React 重做一套完整界面，并补齐这些能力。

> **纯自托管**：没有任何中央服务器、遥测或回连作者的服务；你的数据只存在于你自己的电脑。也因此，**本软件无法像商业产品那样替你承担公网中继与安全责任**——请阅读下面的[安全模型](#安全模型务必阅读)。

## 功能

- **任务（会话）**：新建（可选模式/文件夹/权限/指令）/流式对话/思维链折叠/工具调用卡片/待办清单/排队消息/取消/重命名/复制分支/归档与恢复/置顶/分组
- **附件**：对话中发送图片（内联）与任意文件（dsh 原生上传通道）
- **检索**：跨会话全文搜索（dsh session.search）
- **自动化**：cron 定时任务（`dsh --profile headless` 一次性执行）、运行历史、立即运行
- **技能**：全局与项目技能目录（/name 直接调用）
- **项目**：工作区管理，文件夹折叠
- **统计**：活动热力图（含 dsh 历史回填）、柱状图、模型用量
- **触发器**：会话/回合/自动化事件 → 执行 shell 命令或应用内通知
- **推送**：Bark（iOS）/ ntfy——任务完成、需要审批时推到手机
- **远程控制**：token 配对 + 二维码 + 引导式公网访问向导

## 架构

```
浏览器（桌面/手机） ──HTTP/WS──► gui4dsh 网关 (:7420, token 鉴权)
                                  │  ├─ /api/dsh/*  ──RPC 透传──►  dsh web (:34180, 仅 127.0.0.1)
                                  │  ├─ /ws         ◄─事件桥─ WS /api/remote.mux + $events
                                  │  ├─ /api/fe/*   自有功能（JSON 存储 ~/.gui4dsh/store.json）
                                  │  └─ cron 调度 ──spawn──► dsh --profile headless "任务"
```

网关自动拉起并守护 `dsh web`（崩溃重启）；设置环境变量 `DSH_URL` 可连接已运行的实例。

## 快速开始

```bash
# 方式一：npx（npm 发布后）
npx gui4dsh

# 方式二：源码
git clone <repo> && cd gui4dsh
npm install && npm run build
npm start          # http://127.0.0.1:7420（自动拉起 dsh、打印二维码）
```

首次访问需配对，三种方式任选：

1. **扫码**（推荐）：电脑浏览器自动打开（URL 已含令牌），手机扫终端/设置页二维码
2. **6 位配对码**：电脑端「设置 → 远程访问」查看（一次性、限速），手机输入即可
3. **粘贴令牌**：手动输入完整配对令牌（设置页可查看/重置）

开发模式（HMR）：`npm run dev`（server）+ `npm run dev:web`（vite，代理 /api）。

## 手机远程访问（内置向导）

「设置 → 远程访问」提供分步引导。四条路线，**各付各的代价**：

| 路线 | 首年费用 | 续年费用 | 依赖条件 | 特点 |
|---|---|---|---|---|
| 局域网 | 0 | 0 | 同一 WiFi | 扫码即用 |
| **IPv6 直连 + DNSPod DDNS** | ≈¥10（域名） | ≈¥30-60（域名续费） | 家宽与手机网络都有 IPv6 | 无服务器、直连最快、地址固定、全链路国内 |
| Cloudflare 通道 | 0（临时地址）／域名费（固定地址） | 同左 | 境外网络可达 | 免服务器；大陆直连时好时坏 |
| FRP 自建 | ≈¥30-99（新用户活动价） | ≈¥70-200（**续费原价**） | 一台云服务器 | 最稳定、固定域名 HTTPS；需自维服务器 |

**没有完美方案**：公网可达性必须付出「钱 / 网络条件 / 境外依赖 / 维护精力」之一。向导会自动检测网络环境（IPv6 有无、境外服务可达性）并按实际推荐。**注意表中"¥10/¥30"均为新用户首年价，续费会回到原价**；长期最省的是 IPv6 直连（只有域名续费）。

## 安全模型（务必阅读）

gui4dsh 设计为**单人使用**。把家里电脑暴露到公网前，请理解并接受以下事实：

**已内置的防护**
- 所有 API/WS 需 32 位随机 token；token 可随时重置（全部设备立即失效）
- 6 位配对码：一次性、10 分钟过期、错误尝试限速
- **鉴权失败锁定**：同一 IP 连续 8 次失败封禁 30 分钟
- 远程访问总开关（关掉后仅本机可连）；回环自动配对仅认 127.0.0.1
- 归档恢复等管理操作带运行中会话保护

**仍然存在的风险（使用者自担）**
1. **IPv6 直连路线默认明文 HTTP**：token 在网络中明文传输；FRP/Cloudflare 路线自带 TLS
2. **暴露即会被扫描**：token 是应用层唯一防线；网关代码若有漏洞即可能被利用
3. **家用电脑自身的安全**（系统补丁、其他暴露端口）不在本软件管辖范围
4. 敏感环境请勿直接暴露公网，建议自行叠加 VPN/反向代理/WAF

**免责声明**：本项目以 MIT 协议按"现状"提供，不提供任何形式的担保（安全、可用性、数据完整性）。使用公网映射功能带来的任何损失由使用者自行承担。

## 配置

| 环境变量 | 说明 | 默认 |
|---|---|---|
| `G4D_PORT` | 网关端口 | `7420` |
| `DSH_PORT` | dsh web 内部端口（回环） | `34180` |
| `DSH_URL` | 连接已运行的 dsh（不自行拉起） | 空 |
| `DSH_BIN` | dsh bin.js 绝对路径 | 自动探测 |
| `G4D_DATA_DIR` | 网关数据目录 | `~/.gui4dsh` |
| `DSH_HOME` | dsh 数据目录 | `~/.dsh` |

网关数据（配对令牌、自动化、触发器、分组、统计）存 `~/.gui4dsh/store.json`；会话数据由 dsh 管理（`~/.dsh/`）。Windows 常驻建议用 WinSW/NSSM 注册为服务。

## 项目结构

```
server/   Node 网关：dsh 进程管理、RPC 客户端、事件桥、Fastify API、cron、触发器、统计、推送、frp/cloudflared/DDNS 管理
web/      React 18 + Vite 前端：响应式 UI、i18n（中/英）、zustand + immer 事件折叠
```

## 已知边界

- 依赖 dsh 0.1.5+ 的 Typert RPC 协议；内置自动更新器跟随 npm 最新版，大版本变更可能需等适配
- 自动化任务为 headless 一次性会话，不附加到现有交互会话
- 历史消息超过 40 条通过"加载更早的消息"分页
